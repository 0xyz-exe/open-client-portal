# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Open Client Portal, please send an email to `security@openclientportal.dev`. Please include:
1. Type of vulnerability (e.g. cross-tenant data leakage, authorization bypass, injection).
2. Step-by-step reproduction instructions or proof-of-concept payload.
3. Impact assessment.

We take security seriously and will respond promptly within 48 hours.

See detailed security controls in [docs/SECURITY.md](docs/SECURITY.md).
